# ALAC (Apple Lossless) + MP4 Decoder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a from-scratch, `no_std`, no-alloc ALAC decoder to `soul-audio-core`, riding a new reusable MP4/M4A container reader, wired into the existing `open()`/`AnyDecoder` seam.

**Architecture:** A new `demux/mp4.rs` walks the MP4 box tree (faststart only) to extract the ALAC magic cookie + `mdat`, leaving the source positioned at the audio. A new `formats/alac.rs` decodes the `mdat` bitstream packet-by-packet (packets self-delimit via the ID_END element + byte-align) — adaptive Golomb/Rice residuals → adaptive FIR predictor → stereo un-mix → interleaved `i32`. `probe` gains `ftyp`→`Format::Mp4`; `open()` routes an `alac`-codec MP4 to `AnyDecoder::Alac`.

**Tech Stack:** Rust 1.85 / edition 2024, `#![no_std]` + no-alloc + `#![forbid(unsafe_code)]`. Tests use `include_bytes!` golden fixtures generated by ffmpeg. The authoritative algorithm is Apple's ALAC reference (`macosforge/alac`, Apache-2.0): `ALACDecoder.cpp`, `ag_dec.c`, `dp_dec.c`, `matrix_dec.c`.

## Global Constraints

- `#![no_std]`, no heap allocation anywhere in `soul-audio-core` (fixed by-value buffers only).
- `#![forbid(unsafe_code)]`; no `f32::round`/`floor`/`sin` etc. (std-only) in non-test code.
- Decoders read via the `Source`/`BufSource` capability ladder; output interleaved `i32` through the `Decoder` trait (`stream_info()` + `decode_into(&mut [i32]) -> Result<usize, DecodeError>`; `Ok(0)` = end of stream).
- v1 supports: **faststart** MP4 (`moov` before `mdat`), ALAC **mono + stereo**, bit depths **16 and 24** (also 20/32 where the reference path is identical), decode + `total_frames`. Deferred: seeking (`AnyDecoder::seek_to` returns `DecodeError::Unsupported` for ALAC, exactly like the Ogg-FLAC variant), non-faststart files, >2 channels, AAC.
- All decoded output uses `SampleFormat::Int { bits: bitDepth }` from the cookie.
- New format modules follow the existing pattern: `demux/<c>.rs` container reader + `formats/<c>.rs` decoder, each `pub mod` in its `mod.rs`.
- ALAC config constants (from the cookie of the golden fixture): `frameLength=4096, bitDepth=16, pb=40, mb=10, kb=14, numChannels=2, sampleRate=44100`. Entropy constants: `QBSHIFT=9, QB=512, MMULSHIFT=2, MDENSHIFT=6, MOFF=16, BITOFF=24, MAX_PREFIX=9, MAX_DATATYPE_BITS_16=16, N_MAX_MEAN_CLAMP=0xFFFF`.

```rust
//! Minimal, forward-streaming MP4/M4A box reader for **faststart** files
//! (`moov` before `mdat`). It walks the box tree to the `stsd`→`alac` sample
//! entry (extracting the ALAC magic cookie), reads `mdhd` for the duration, and
//! stops at `mdat` with the source positioned on the audio. Structured so the
//! sample tables (`stsz`/`stco`, for seeking) and the `mp4a` entry (for AAC)
//! are additive.

use crate::decoder::DecodeError;
use crate::io::{BufSource, Source};
use embedded_io::Read;

/// The 24-byte `ALACSpecificConfig` from the `stsd`→`alac` cookie (big-endian on
/// disk; the fields we need for decode).
#[derive(Clone, Copy, Debug)]
pub struct AlacConfig {
    pub frame_length: u32,
    pub bit_depth: u8,
    pub pb: u8,
    pub mb: u8,
    pub kb: u8,
    pub channels: u8,
    pub sample_rate: u32,
    pub max_frame_bytes: u32,
}

/// A parsed MP4 header positioned at `mdat` audio.
pub struct Mp4Reader<S> {
    src: S,
    config: AlacConfig,
    total_samples: u64,
    mdat_remaining: u64,
}

/// Read exactly `N` bytes or error `Malformed`.
fn read_exact<S: Source, const N: usize>(src: &mut S) -> Result<[u8; N], DecodeError> {
    let mut buf = [0u8; N];
    src.read_exact(&mut buf).map_err(|_| DecodeError::Malformed)?;
    Ok(buf)
}

/// Discard `n` bytes from a forward source.
fn skip<S: Source>(src: &mut S, mut n: u64) -> Result<(), DecodeError> {
    let mut scratch = [0u8; 512];
    while n > 0 {
        let want = n.min(scratch.len() as u64) as usize;
        let got = src.read(&mut scratch[..want]).map_err(|_| DecodeError::Io)?;
        if got == 0 {
            return Err(DecodeError::Malformed);
        }
        n -= got as u64;
    }
    Ok(())
}

fn be32(b: &[u8]) -> u32 {
    u32::from_be_bytes([b[0], b[1], b[2], b[3]])
}
fn be64(b: &[u8]) -> u64 {
    u64::from_be_bytes([b[0], b[1], b[2], b[3], b[4], b[5], b[6], b[7]])
}

/// Read a box header: returns `(content_len, fourcc, header_len)`. `content_len`
/// excludes the header. Handles 64-bit sizes (`size == 1`).
fn box_header<S: Source>(src: &mut S) -> Result<(u64, [u8; 4], u64), DecodeError> {
    let hdr: [u8; 8] = read_exact(src)?;
    let size32 = be32(&hdr[0..4]);
    let fourcc = [hdr[4], hdr[5], hdr[6], hdr[7]];
    if size32 == 1 {
        let big: [u8; 8] = read_exact(src)?;
        let size = be64(&big);
        Ok((size.saturating_sub(16), fourcc, 16))
    } else if size32 == 0 {
        // "to end of file" — not expected before mdat in faststart.
        Err(DecodeError::Unsupported)
    } else {
        Ok((u64::from(size32).saturating_sub(8), fourcc, 8))
    }
}

impl<S: BufSource> Mp4Reader<S> {
    /// Parse the header of a faststart ALAC `.m4a`, leaving `src` at `mdat`.
    ///
    /// # Errors
    /// [`DecodeError::Unsupported`] for non-faststart / non-ALAC / missing boxes;
    /// [`DecodeError::Malformed`] on truncation.
    pub fn new(mut src: S) -> Result<Self, DecodeError> {
        let mut config: Option<AlacConfig> = None;
        let mut total_samples: u64 = 0;
        loop {
            let (len, fourcc, _) = box_header(&mut src)?;
            match &fourcc {
                b"moov" => {
                    let (c, ts) = parse_moov(&mut src, len)?;
                    config = Some(c);
                    total_samples = ts;
                }
                b"mdat" => {
                    let config = config.ok_or(DecodeError::Unsupported)?; // moov must precede mdat
                    return Ok(Self { src, config, total_samples, mdat_remaining: len });
                }
                _ => skip(&mut src, len)?, // ftyp, free, udta, ...
            }
        }
    }

    pub fn config(&self) -> &AlacConfig {
        &self.config
    }
    pub fn total_samples(&self) -> u64 {
        self.total_samples
    }
    pub fn mdat_remaining(&self) -> u64 {
        self.mdat_remaining
    }
    pub fn src_mut(&mut self) -> &mut S {
        &mut self.src
    }
}

/// Descend `moov`→`trak`→`mdia`→(`mdhd`,`minf`→`stbl`→`stsd`). Returns the ALAC
/// config and the total per-channel sample count.
fn parse_moov<S: BufSource>(src: &mut S, len: u64) -> Result<(AlacConfig, u64), DecodeError> {
    descend_for(src, len, b"trak", |src, len| {
        descend_for(src, len, b"mdia", |src, len| {
            let mut total = 0u64;
            let mut config = None;
            let mut remaining = len;
            while remaining >= 8 {
                let (l, f, h) = box_header(src)?;
                remaining -= l + h;
                match &f {
                    b"mdhd" => total = parse_mdhd(src, l)?,
                    b"minf" => {
                        config = Some(descend_for(src, l, b"stbl", |src, len| {
                            descend_for(src, len, b"stsd", parse_stsd)
                        })?);
                    }
                    _ => skip(src, l)?,
                }
            }
            let config = config.ok_or(DecodeError::Unsupported)?;
            Ok((config, total))
        })
    })
}

/// Read boxes within `[0,len)` until one matches `want`, then run `f` on its
/// content; skip others. Errors `Unsupported` if `want` is not found.
fn descend_for<S, R>(
    src: &mut S,
    len: u64,
    want: &[u8; 4],
    f: impl FnOnce(&mut S, u64) -> Result<R, DecodeError>,
) -> Result<R, DecodeError>
where
    S: BufSource,
{
    let mut remaining = len;
    while remaining >= 8 {
        let (l, fourcc, h) = box_header(src)?;
        remaining -= l + h;
        if &fourcc == want {
            return f(src, l);
        }
        skip(src, l)?;
    }
    Err(DecodeError::Unsupported)
}

/// `mdhd`: version(1)+flags(3), then (v0) creation/mod u32 + timescale u32 +
/// duration u32, or (v1) u64 times + timescale u32 + duration u64. Returns the
/// duration in timescale units (== per-channel sample count for audio).
fn parse_mdhd<S: Source>(src: &mut S, len: u64) -> Result<u64, DecodeError> {
    let head: [u8; 4] = read_exact(src)?;
    let version = head[0];
    if version == 1 {
        let b: [u8; 28] = read_exact(src)?; // 8+8 times, 4 timescale, 8 duration
        let duration = be64(&b[20..28]);
        skip(src, len - 4 - 28)?;
        Ok(duration)
    } else {
        let b: [u8; 16] = read_exact(src)?; // 4+4 times, 4 timescale, 4 duration
        let duration = u64::from(be32(&b[12..16]));
        skip(src, len - 4 - 16)?;
        Ok(duration)
    }
}

/// `stsd`: version+flags(4) + entry_count(4), then the sample entry. For `alac`,
/// skip 8 (entry box header) + 28 (AudioSampleEntry body) + 12 (inner `alac`
/// FullBox header) to reach the 24-byte config.
fn parse_stsd<S: Source>(src: &mut S, len: u64) -> Result<AlacConfig, DecodeError> {
    let _vf_count: [u8; 8] = read_exact(src)?;
    let (entry_len, fourcc, _h) = box_header(src)?;
    if &fourcc != b"alac" {
        return Err(DecodeError::Unsupported); // e.g. mp4a (AAC) — future
    }
    // AudioSampleEntry body (28) + inner alac FullBox header (12) = 40, then the
    // 24-byte config; then skip the remainder of the entry and stsd.
    skip(src, 28 + 12)?;
    let c: [u8; 24] = read_exact(src)?;
    let consumed = 8 /*stsd vf+count*/ + 8 /*entry hdr*/ + 28 + 12 + 24;
    let _ = (entry_len, consumed);
    // Skip whatever remains of stsd after the config.
    let after = len - 8 - 8 - 28 - 12 - 24;
    skip(src, after)?;
    Ok(AlacConfig {
        frame_length: be32(&c[0..4]),
        bit_depth: c[5],
        pb: c[6],
        mb: c[7],
        kb: c[8],
        channels: c[9],
        max_frame_bytes: be32(&c[12..16]),
        sample_rate: be32(&c[20..24]),
    })
}
```

```rust
//! ALAC (Apple Lossless) decoder — decodes an `mdat` ALAC bitstream (from the
//! MP4 reader) to interleaved `i32`. Algorithm transcribed from Apple's
//! reference (`macosforge/alac`, Apache-2.0): `ALACDecoder.cpp`, `ag_dec.c`,
//! `dp_dec.c`, `matrix_dec.c`.

/// MSB-first bit reader over a byte slice. Reads past the end return zero-padded
/// bits (a truncated final frame is tolerated).
struct BitReader<'a> {
    data: &'a [u8],
    bit_pos: usize,
}

impl<'a> BitReader<'a> {
    fn new(data: &'a [u8]) -> Self {
        Self { data, bit_pos: 0 }
    }

    fn byte(&self, i: usize) -> u32 {
        self.data.get(i).copied().map_or(0, u32::from)
    }

    /// Read `n` bits (n ≤ 16), MSB-first, right-aligned.
    fn read(&mut self, n: u32) -> u32 {
        let byte = self.bit_pos >> 3;
        let bit = (self.bit_pos & 7) as u32;
        let window = (self.byte(byte) << 16) | (self.byte(byte + 1) << 8) | self.byte(byte + 2);
        let v = ((window << bit) & 0x00FF_FFFF) >> (24 - n);
        self.bit_pos += n as usize;
        v
    }

    /// Read `n` bits (n ≤ 32).
    fn read_long(&mut self, n: u32) -> u32 {
        if n <= 16 {
            self.read(n)
        } else {
            let hi = self.read(16);
            let lo = self.read(n - 16);
            (hi << (n - 16)) | lo
        }
    }

    fn read_one(&mut self) -> u32 {
        let v = (self.byte(self.bit_pos >> 3) >> (7 - (self.bit_pos & 7) as u32)) & 1;
        self.bit_pos += 1;
        v
    }

    fn byte_align(&mut self) {
        let rem = self.bit_pos & 7;
        if rem != 0 {
            self.bit_pos += 8 - rem;
        }
    }

    fn advance(&mut self, n: usize) {
        self.bit_pos += n;
    }
    fn bit_pos(&self) -> usize {
        self.bit_pos
    }
    fn set_bit_pos(&mut self, p: usize) {
        self.bit_pos = p;
    }

    /// Big-endian 32-bit window at the current position, left-aligned (top bit =
    /// next bit to read). Used by the entropy stage which computes prefixes.
    fn peek32(&self) -> u32 {
        let byte = self.bit_pos >> 3;
        let bit = (self.bit_pos & 7) as u32;
        let w = (self.byte(byte) << 24)
            | (self.byte(byte + 1) << 16)
            | (self.byte(byte + 2) << 8)
            | self.byte(byte + 3);
        if bit == 0 { w } else { (w << bit) | (self.byte(byte + 4) >> (8 - bit)) }
    }
}
```

- [ ] **Step 3: Implement the adaptive Golomb/Rice decoder**

Add to `formats/alac.rs`. `dyn_decomp` fills `pc[0..num]` with residuals from the bit reader:

```rust
fn lead(x: u32) -> u32 {
    x.leading_zeros() // lead(0) == 32, matching the reference
}

/// `lg3a(x) = 31 - lead(x+3)` ≈ floor(log2(x+3)).
fn lg3a(x: u32) -> u32 {
    31 - lead(x.wrapping_add(3))
}

/// Read one Golomb value with parameter `m = (1<<k)-1`, quotient escape at
/// prefix ≥ MAX_PREFIX (→ literal of `maxbits`).
fn dyn_get_32bit(r: &mut BitReader, k: u32, maxbits: u32) -> u32 {
    let stream = r.peek32();
    let prefix = lead(!stream);
    if prefix >= MAX_PREFIX {
        r.advance(MAX_PREFIX as usize);
        return r.read_long(maxbits);
    }
    let m = (1u32 << k) - 1;
    r.advance((prefix + 1) as usize); // 'prefix' ones + terminating zero
    if k != 1 {
        let v = (stream << (prefix + 1)) >> (32 - k); // next k bits
        r.advance((k - 1) as usize);
        let mut result = prefix * m;
        if v >= 2 {
            result += v - 1;
            r.advance(1);
        }
        result
    } else {
        prefix
    }
}

/// Zero-run reader (16-bit variant): always consumes `k` remainder bits.
fn dyn_get_16bit(r: &mut BitReader, mz: u32, k: u32) -> u32 {
    let stream = r.peek32();
    let prefix = lead(!stream);
    if prefix >= MAX_PREFIX {
        r.advance(MAX_PREFIX as usize);
        return r.read_long(MAX_DATATYPE_BITS_16);
    }
    r.advance((prefix + 1) as usize);
    let v = (stream << (prefix + 1)) >> (32 - k);
    if v < 2 {
        r.advance((k - 1) as usize);
        prefix * mz
    } else {
        r.advance(k as usize);
        prefix * mz + v - 1
    }
}

/// `dyn_decomp`: decode `num` residuals into `pc`. `maxbits = chan_bits`.
fn dyn_decomp(
    r: &mut BitReader,
    pc: &mut [i32],
    num: usize,
    chan_bits: u32,
    mb0: u32,
    pb: u32,
    kb: u32,
) {
    let wb = (1u32 << kb) - 1;
    let mut mb = mb0;
    let mut zmode = 0u32;
    let mut c = 0usize;
    while c < num {
        let mut k = lg3a(mb >> QBSHIFT);
        k = k.min(kb);
        let n = dyn_get_32bit(r, k, chan_bits);

        let ndecode = n + zmode;
        let del = if ndecode & 1 != 0 {
            -(((ndecode + 1) >> 1) as i32)
        } else {
            ((ndecode + 1) >> 1) as i32
        };
        pc[c] = del;
        c += 1;

        // mb = pb*(n+zmode) + mb - ((pb*mb) >> QBSHIFT)
        mb = pb.wrapping_mul(n + zmode).wrapping_add(mb).wrapping_sub((pb.wrapping_mul(mb)) >> QBSHIFT);
        if n > N_MAX_MEAN_CLAMP {
            mb = N_MAX_MEAN_CLAMP;
        }
        zmode = 0;

        if ((mb << MMULSHIFT) < QB as u32) && c < num {
            zmode = 1;
            let kz = (lead(mb) as i32 - BITOFF + ((mb as i32 + MOFF) >> MDENSHIFT)) as u32;
            let mz = ((1u32 << kz) - 1) & wb;
            let run = dyn_get_16bit(r, mz, kz) as usize;
            for _ in 0..run {
                if c >= num {
                    break;
                }
                pc[c] = 0;
                c += 1;
            }
            if run >= 65535 {
                zmode = 0;
            }
            mb = 0;
        }
    }
}
```

- [ ] **Step 4: Implement the adaptive FIR predictor**

```rust
fn sign_of(x: i32) -> i32 {
    (x >> 31) | ((-x >> 31) & 1) // -1, 0, or +1
}

/// `unpc_block`: reconstruct `out[0..num]` from residuals `pc1`, `numactive`
/// coefficients (`coefs`), `chan_bits`, `denshift`.
fn unpc_block(
    pc1: &[i32],
    out: &mut [i32],
    num: usize,
    coefs: &mut [i32],
    numactive: usize,
    chan_bits: u32,
    denshift: u32,
) {
    let chanshift = 32 - chan_bits;
    let denhalf = 1i32 << (denshift - 1);

    out[0] = pc1[0];
    if numactive == 0 {
        out[..num].copy_from_slice(&pc1[..num]);
        return;
    }
    if numactive == 31 {
        // order-31 long-term integrator
        let mut prev = out[0];
        for j in 1..num {
            let del = pc1[j].wrapping_add(prev);
            prev = (del << chanshift) >> chanshift;
            out[j] = prev;
        }
        return;
    }

    // warm-up: first `numactive` samples via a first-order integrator
    for j in 1..=numactive {
        let del = pc1[j].wrapping_add(out[j - 1]);
        out[j] = (del << chanshift) >> chanshift;
    }
    let lim = numactive + 1;
    for j in lim..num {
        let top = out[j - lim]; // out[j - numactive - 1]
        let mut sum1 = 0i64;
        for k in 0..numactive {
            sum1 += i64::from(coefs[k]) * i64::from(out[j - 1 - k] - top);
        }
        let mut del0 = pc1[j];
        let sg = sign_of(pc1[j]);
        let del = pc1[j]
            .wrapping_add(top)
            .wrapping_add(((sum1 + i64::from(denhalf)) >> denshift) as i32);
        out[j] = (del << chanshift) >> chanshift;

        // sign-sign LMS
        if sg > 0 {
            for k in (0..numactive).rev() {
                let dd = top - out[j - 1 - k];
                let sgn = sign_of(dd);
                coefs[k] -= sgn;
                del0 -= ((numactive - k) as i32) * ((sgn * dd) >> denshift);
                if del0 <= 0 {
                    break;
                }
            }
        } else if sg < 0 {
            for k in (0..numactive).rev() {
                let dd = top - out[j - 1 - k];
                let sgn = sign_of(dd);
                coefs[k] += sgn;
                del0 -= ((numactive - k) as i32) * ((-sgn * dd) >> denshift);
                if del0 >= 0 {
                    break;
                }
            }
        }
    }
}
```

```rust
use crate::decoder::{DecodeError, Decoder};
use crate::demux::mp4::{AlacConfig, Mp4Reader};
use crate::io::BufSource;
use crate::model::{SampleFormat, StreamInfo};
use embedded_io::Read;

pub struct AlacDecoder<S> {
    reader: Mp4Reader<S>,
    // Whole-mdat buffer? No — stream per-packet. We hold a packet-sized byte
    // buffer + decoded-sample scratch, all fixed-size (no alloc).
    packet: [u8; MAX_FRAME * 2 * 2 + 1024], // >= max_frame_bytes for mono/stereo 16-bit
    mix: [[i32; MAX_FRAME]; MAX_CHANNELS],
    resid: [i32; MAX_FRAME],
    out_frames: [i32; MAX_FRAME * MAX_CHANNELS], // interleaved, ready to hand out
    out_len: usize,                              // valid interleaved samples in out_frames
    out_pos: usize,                              // next to emit
    samples_left: u64,
    channels: usize,
    bit_depth: u8,
    sample_rate: u32,
    frame_length: usize,
    pb: u32,
    mb: u32,
    kb: u32,
    eof: bool,
}

impl<S: BufSource> AlacDecoder<S> {
    /// Parse the MP4 header and prepare to stream ALAC packets.
    ///
    /// # Errors
    /// [`DecodeError::Unsupported`] for >2 channels or a frame length beyond the
    /// fixed buffer; container errors from [`Mp4Reader`].
    pub fn new(src: S) -> Result<Self, DecodeError> {
        let reader = Mp4Reader::new(src)?;
        let c: AlacConfig = *reader.config();
        if c.channels == 0 || c.channels as usize > MAX_CHANNELS {
            return Err(DecodeError::Unsupported);
        }
        if c.frame_length as usize > MAX_FRAME {
            return Err(DecodeError::Unsupported);
        }
        Ok(Self {
            samples_left: reader.total_samples(),
            channels: c.channels as usize,
            bit_depth: c.bit_depth,
            sample_rate: c.sample_rate,
            frame_length: c.frame_length as usize,
            pb: u32::from(c.pb),
            mb: u32::from(c.mb),
            kb: u32::from(c.kb),
            reader,
            packet: [0u8; MAX_FRAME * 2 * 2 + 1024],
            mix: [[0i32; MAX_FRAME]; MAX_CHANNELS],
            resid: [0i32; MAX_FRAME],
            out_frames: [0i32; MAX_FRAME * MAX_CHANNELS],
            out_len: 0,
            out_pos: 0,
            eof: false,
        })
    }

    pub fn total_frames(&self) -> Option<u64> {
        Some(self.reader.total_samples())
    }

    /// Read the next packet's bytes into `self.packet`. Packets self-delimit, so
    /// we read up to `max_frame_bytes` (bounded by `packet.len()` and the mdat
    /// remaining) — the decoder consumes only the packet's bits and the rest is
    /// re-used on the next call by tracking the consumed byte count.
    ///
    /// Because the byte reader is forward-only, we keep an internal carry of
    /// bytes already read but not yet consumed by a decoded packet.
    fn decode_next_packet(&mut self) -> Result<bool, DecodeError> {
        // Implementation note for the engineer:
        //   Maintain `self.packet` as a sliding buffer with `filled`/`used`
        //   cursors (add `filled: usize, used: usize` fields). On each call:
        //     1. shift unconsumed bytes (`packet[used..filled]`) to the front,
        //     2. refill from `reader.src_mut()` up to `min(packet.len(),
        //        mdat_remaining)`,
        //     3. run `decode_packet` on `packet[..filled]`, which returns the
        //        number of BYTES consumed (bit_pos rounded up after byte-align)
        //        and the number of FRAMES produced,
        //     4. advance `used` by the consumed bytes and decrement
        //        `mdat_remaining`/`samples_left`.
        //   Stop when `samples_left == 0` or `mdat_remaining == 0`.
        // (Fields `filled`/`used`/`mdat_remaining` are added to the struct; keep
        //  them in sync with the reader.)
        unimplemented!("see decode_packet below; wire the sliding buffer")
    }

    /// Decode one ALAC packet from `data`, writing interleaved samples into
    /// `self.out_frames`. Returns `(bytes_consumed, frames)`.
    fn decode_packet(&mut self, data: &[u8]) -> Result<(usize, usize), DecodeError> {
        let mut r = BitReader::new(data);
        let mut coefs = [[0i32; 32]; MAX_CHANNELS];
        let mut num_samples = self.frame_length;
        let mut ch_index = 0usize;
        let mut produced = 0usize;

        loop {
            let tag = r.read(3);
            match tag {
                0 | 3 => {
                    // SCE / LFE — mono element
                    self.decode_channel_element(&mut r, 1, &mut coefs, ch_index, &mut num_samples)?;
                    ch_index += 1;
                }
                1 => {
                    // CPE — stereo element
                    self.decode_channel_element(&mut r, 2, &mut coefs, ch_index, &mut num_samples)?;
                    ch_index += 2;
                }
                4 => {
                    // DSE — data stream element, skip
                    let _tag = r.read(4);
                    let align = r.read_one();
                    let mut count = r.read(8);
                    if count == 255 {
                        count += r.read(8);
                    }
                    if align != 0 {
                        r.byte_align();
                    }
                    r.advance((count * 8) as usize);
                }
                6 => {
                    // FIL — fill element, skip
                    let mut count = r.read(4);
                    if count == 15 {
                        count += r.read(8) - 1;
                    }
                    r.advance((count * 8) as usize);
                }
                7 => {
                    r.byte_align();
                    break; // END
                }
                _ => return Err(DecodeError::Unsupported), // CCE/PCE
            }
            if ch_index >= self.channels {
                // still must consume the END tag; continue the loop to hit it
            }
        }

        produced = num_samples;
        let bytes = (r.bit_pos() + 7) / 8;
        // Interleave mix[] into out_frames (native samples, i32).
        self.interleave(num_samples);
        Ok((bytes, produced))
    }

    /// Decode one SCE(1)/CPE(2) element into `self.mix[ch_index..]`.
    fn decode_channel_element(
        &mut self,
        r: &mut BitReader,
        elem_ch: usize,
        coefs: &mut [[i32; 32]; MAX_CHANNELS],
        ch_index: usize,
        num_samples: &mut usize,
    ) -> Result<(), DecodeError> {
        let _instance = r.read(4);
        let unused = r.read(12);
        if unused != 0 {
            return Err(DecodeError::Malformed);
        }
        let header = r.read(4);
        let partial = header >> 3;
        let bytes_shifted = (header >> 1) & 0x3;
        let escape = header & 0x1;
        if bytes_shifted == 3 {
            return Err(DecodeError::Malformed);
        }
        if partial != 0 {
            let hi = r.read(16);
            let lo = r.read(16);
            *num_samples = ((hi << 16) | lo) as usize;
        }
        let num = *num_samples;
        let shift = bytes_shifted * 8;

        if escape != 0 {
            // Verbatim path (rare).
            let chan_bits = u32::from(self.bit_depth); // stereo uses bitDepth (not +1) in escape
            let sh = 32 - chan_bits;
            for e in 0..elem_ch {
                for i in 0..num {
                    let v = if chan_bits <= 16 {
                        ((r.read(chan_bits) << sh) as i32) >> sh
                    } else {
                        let hi = ((r.read(16) << 16) as i32) >> sh;
                        hi | r.read(chan_bits - 16) as i32
                    };
                    self.mix[ch_index + e][i] = v;
                }
            }
            return Ok(());
        }

        // Compressed path.
        let mix_bits = r.read(8);
        let mix_res = (r.read(8) as i8) as i32;

        // Per-element channel bit width.
        let base = u32::from(self.bit_depth) - shift;
        let chan_bits = if elem_ch == 2 { base + 1 } else { base };

        // Read predictor params + coefficients for each channel of the element,
        // decode residuals, run the predictor.
        let mut modes = [0u32; 2];
        let mut denshifts = [0u32; 2];
        let mut nums = [0usize; 2];
        for e in 0..elem_ch {
            let h0 = r.read(8);
            modes[e] = h0 >> 4;
            denshifts[e] = h0 & 0xF;
            let h1 = r.read(8);
            let pb_factor = h1 >> 5;
            nums[e] = (h1 & 0x1F) as usize;
            for k in 0..nums[e] {
                coefs[ch_index + e][k] = (r.read(16) as i16) as i32;
            }
            let _ = pb_factor; // captured below
        }

        // Wasted ("shift") bits: skip now, read after prediction.
        let shift_pos = r.bit_pos();
        if bytes_shifted != 0 {
            r.advance((shift * elem_ch as u32 * num as u32) as usize);
        }

        for e in 0..elem_ch {
            // pb effective = (pb * pbFactor) / 4 — re-read pbFactor from header we
            // parsed; recompute here by re-deriving from stored state:
            // (store pb_factor per channel in a local array in the loop above)
        }

        // NOTE for engineer: fold the two loops — decode residuals with
        // `dyn_decomp(r, &mut self.resid, num, chan_bits, mb<<... , pb_eff, kb)`
        // then `unpc_block(&self.resid, &mut self.mix[ch_index+e], num,
        // &mut coefs[ch_index+e][..nums[e]], nums[e], chan_bits, denshifts[e])`,
        // handling `mode != 0` (order-31 integrator first). `mb0` passed to
        // dyn_decomp is the config `mb` (10). `pb_eff = (self.pb * pb_factor)/4`.

        // Re-read shift bits (if any) into a per-sample shift buffer and reassemble.
        if bytes_shifted != 0 {
            let save = r.bit_pos();
            r.set_bit_pos(shift_pos);
            // stereo: interleaved L,R shift words; mono: one per sample.
            // shiftbuf[e][i] = r.read(shift); apply after un-mix.
            r.set_bit_pos(save);
        }

        // Stereo un-mix (CPE) using mix_bits/mix_res; SCE copies mix[.] as-is.
        if elem_ch == 2 {
            for i in 0..num {
                let u = self.mix[ch_index][i];
                let v = self.mix[ch_index + 1][i];
                let l = if mix_res != 0 {
                    u + v - ((mix_res * v) >> mix_bits)
                } else {
                    u
                };
                let rr = if mix_res != 0 { l - v } else { v };
                self.mix[ch_index][i] = l;
                self.mix[ch_index + 1][i] = rr;
            }
        }
        Ok(())
    }

    /// Interleave `self.mix[0..channels][0..num]` into `self.out_frames`, mapping
    /// the internal 32-bit samples to native `bit_depth` values (right-justified).
    fn interleave(&mut self, num: usize) {
        let ch = self.channels;
        for i in 0..num {
            for c in 0..ch {
                self.out_frames[i * ch + c] = self.mix[c][i];
            }
        }
        self.out_len = num * ch;
        self.out_pos = 0;
    }
}

impl<S: BufSource> Decoder for AlacDecoder<S> {
    fn stream_info(&self) -> StreamInfo {
        StreamInfo {
            sample_rate: self.sample_rate,
            channels: self.channels as u16,
            format: SampleFormat::Int { bits: self.bit_depth },
        }
    }

    fn decode_into(&mut self, out: &mut [i32]) -> Result<usize, DecodeError> {
        let mut written = 0;
        while written < out.len() {
            if self.out_pos >= self.out_len {
                if self.eof || self.samples_left == 0 {
                    break;
                }
                if !self.decode_next_packet()? {
                    self.eof = true;
                    break;
                }
            }
            let n = (out.len() - written).min(self.out_len - self.out_pos);
            out[written..written + n]
                .copy_from_slice(&self.out_frames[self.out_pos..self.out_pos + n]);
            self.out_pos += n;
            written += n;
        }
        Ok(written)
    }
}
```
