# soul-audio-artbake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bake cover art into a 1-bit grayscale `art.blob` the e-ink DAP reads via `ArtStore`, deduped per album, wired through the importer + baker, with `art_id` source-routed in `MultiCatalog`.

**Architecture:** A new `soul-audio-artbake` crate with the same read/write split as `soul-audio-index`: `default` = no_std no-alloc `ArtBlobReader` (impl `ArtStore`); `build` feature = std writer + an `image`-based Floyd-Steinberg encoder. The shared importer discovers covers; the baker encodes/dedups them into `/.soulidx/art.blob` and assigns `art_id`s.

**Tech Stack:** Rust (edition 2024, rust-version 1.85), `no_std` + `alloc`, `embedded-io` 0.6, `image` 0.25 (build-only), `SliceSource`/`SeekSource` from `soul-audio-core`.

## Global Constraints

- **Conventional Commits** required; commit messages carry **no** AI/Claude/Anthropic/co-author/"Generated with" text (enforced by `cargo xtask check-commit-msg`).
- `soul-audio-artbake` **default** must build for `thumbv7em-none-eabihf --no-default-features` and `forbid(unsafe_code)`; the `image` dep lives **only** under `build`.
- `art_id 0` is the **no-art sentinel** everywhere (records, reader, MultiCatalog packing).
- 1-bit bitmap packing: **MSB-first**, row-major, each row padded to a byte boundary; `row_bytes = (width + 7) / 8`; `bit = 1` → black (ink).

- Branch: `feat/artbake` (off `main`); PR targets `dev` (scoped gate). The spec is `docs/superpowers/specs/2026-11-09-artbake-design.md`.

use soul_audio_artbake::{ArtBlobReader, HEADER_LEN, ENTRY_LEN};
use soul_audio_catalog::ArtStore;
use soul_audio_core::SliceSource;

fn blob() -> Vec<u8> {
    let bitmaps: [[u8; 2]; 2] = [[0b1010_1010, 0b0101_0101], [0xFF, 0x00]];
    let mut v = Vec::new();
    v.extend_from_slice(b"SART");            // magic
    v.push(1); v.push(0);                    // version, flags
    v.extend_from_slice(&8u16.to_le_bytes()); // width
    v.extend_from_slice(&2u16.to_le_bytes()); // height
    v.extend_from_slice(&2u32.to_le_bytes()); // count
    v.extend_from_slice(&0u16.to_le_bytes()); // pad
    let first = (HEADER_LEN + 2 * ENTRY_LEN) as u32;
    for (i, _) in bitmaps.iter().enumerate() {
        v.extend_from_slice(&(first + i as u32 * 2).to_le_bytes()); // offset
        v.extend_from_slice(&2u32.to_le_bytes());                   // len
    }
    for b in bitmaps { v.extend_from_slice(&b); }
    v
}

- [ ] **Step 4: Implement `src/lib.rs`** (no_std; header read in `new`; `art` seeks the entry):

```rust
#![cfg_attr(not(feature = "std"), no_std)]
#![forbid(unsafe_code)]

use embedded_io::{Read, Seek, SeekFrom};
use soul_audio_catalog::{ArtStore, CatalogError};
use soul_audio_core::SeekSource;

pub const MAGIC: [u8; 4] = *b"SART";
pub const FORMAT_VERSION: u8 = 1;
pub const HEADER_LEN: usize = 16;
pub const ENTRY_LEN: usize = 8;

#[must_use]
pub fn row_bytes(width: u16) -> usize { (width as usize + 7) / 8 }

fn le_u16(b: &[u8], o: usize) -> u16 { u16::from_le_bytes([b[o], b[o + 1]]) }
fn le_u32(b: &[u8], o: usize) -> u32 { u32::from_le_bytes([b[o], b[o+1], b[o+2], b[o+3]]) }

pub struct ArtBlobReader<S> {
    src: core::cell::RefCell<S>,
    width: u16,
    height: u16,
    count: u32,
}

impl<S: SeekSource> ArtBlobReader<S> {
    #[must_use]
    pub fn new(mut src: S) -> Self {
        let mut h = [0u8; HEADER_LEN];
        let _ = src.seek(SeekFrom::Start(0));
        let _ = src.read(&mut h); // best-effort; a bad/absent blob → count 0
        let ok = h[..4] == MAGIC;
        Self {
            src: core::cell::RefCell::new(src),
            width:  if ok { le_u16(&h, 6) } else { 0 },
            height: if ok { le_u16(&h, 8) } else { 0 },
            count:  if ok { le_u32(&h, 10) } else { 0 },
        }
    }
    #[must_use] pub fn dimensions(&self) -> (u16, u16) { (self.width, self.height) }
    #[must_use] pub fn count(&self) -> u32 { self.count }
}

impl<S: SeekSource> ArtStore for ArtBlobReader<S> {
    fn art(&self, art_id: u32, buf: &mut [u8]) -> Result<usize, CatalogError> {
        if art_id == 0 { return Ok(0); }
        if art_id > self.count { return Err(CatalogError::OutOfRange); }
        let mut s = self.src.borrow_mut();
        let ent = HEADER_LEN as u64 + u64::from(art_id - 1) * ENTRY_LEN as u64;
        let mut e = [0u8; ENTRY_LEN];
        s.seek(SeekFrom::Start(ent)).map_err(|_| CatalogError::Corrupt)?;
        s.read_exact(&mut e).map_err(|_| CatalogError::Corrupt)?;
        let (off, len) = (le_u32(&e, 0), le_u32(&e, 4) as usize);
        if buf.len() < len { return Err(CatalogError::Truncated); }
        s.seek(SeekFrom::Start(u64::from(off))).map_err(|_| CatalogError::Corrupt)?;
        s.read_exact(&mut buf[..len]).map_err(|_| CatalogError::Corrupt)?;
        Ok(len)
    }
}
```

- [ ] **Step 4: Implement `src/build.rs`.** Encoder:

```rust
use alloc::vec::Vec;
use alloc::collections::BTreeMap;
use image::imageops::FilterType;
use crate::{row_bytes, MAGIC, FORMAT_VERSION, HEADER_LEN, ENTRY_LEN};

#[derive(Debug)] pub enum ArtError { Decode }

pub fn encode_cover(bytes: &[u8], width: u16, height: u16) -> Result<Vec<u8>, ArtError> {
    let img = image::load_from_memory(bytes).map_err(|_| ArtError::Decode)?;
    let gray = img.to_luma8();
    let small = image::imageops::resize(&gray, width as u32, height as u32, FilterType::Triangle);
    // Floyd-Steinberg over an i16 error buffer.
    let (w, h) = (width as usize, height as usize);
    let mut px: Vec<i16> = small.as_raw().iter().map(|&p| p as i16).collect();
    let rb = row_bytes(width);
    let mut out = alloc::vec![0u8; rb * h];
    for y in 0..h {
        for x in 0..w {
            let i = y * w + x;
            let old = px[i];
            let new = if old < 128 { 0 } else { 255 };
            if new == 0 { out[y * rb + (x >> 3)] |= 0x80 >> (x & 7); } // 1 = ink (dark)
            let err = old - new;
            let mut diffuse = |xx: isize, yy: isize, f: i16| {
                if xx >= 0 && xx < w as isize && yy < h as isize {
                    let j = yy as usize * w + xx as usize;
                    px[j] = (px[j] + err * f / 16).clamp(0, 255);
                }
            };
            diffuse(x as isize + 1, y as isize,     7);
            diffuse(x as isize - 1, y as isize + 1, 3);
            diffuse(x as isize,     y as isize + 1, 5);
            diffuse(x as isize + 1, y as isize + 1, 1);
        }
    }
    Ok(out)
}
```

Writer (dedup by a FNV-1a hash of the bitmap; `finish` lays out header + table + bitmaps):

```rust
pub struct ArtBlobWriter { width: u16, height: u16, entries: Vec<Vec<u8>>, seen: BTreeMap<u64, u32> }
impl ArtBlobWriter {
    pub fn new(width: u16, height: u16) -> Self { Self { width, height, entries: Vec::new(), seen: BTreeMap::new() } }
    pub fn add(&mut self, bitmap: Vec<u8>) -> u32 {
        let mut hash = 0xcbf29ce484222325u64;
        for &b in &bitmap { hash ^= b as u64; hash = hash.wrapping_mul(0x100000001b3); }
        if let Some(&id) = self.seen.get(&hash) { return id; }
        self.entries.push(bitmap);
        let id = self.entries.len() as u32; // 1-based art_id
        self.seen.insert(hash, id);
        id
    }
    pub fn finish(self) -> Vec<u8> {
        let count = self.entries.len();
        let table = HEADER_LEN + count * ENTRY_LEN;
        let mut out = Vec::with_capacity(table + self.entries.iter().map(|e| e.len()).sum::<usize>());
        out.extend_from_slice(&MAGIC);
        out.push(FORMAT_VERSION); out.push(0);
        out.extend_from_slice(&self.width.to_le_bytes());
        out.extend_from_slice(&self.height.to_le_bytes());
        out.extend_from_slice(&(count as u32).to_le_bytes());
        out.extend_from_slice(&0u16.to_le_bytes());
        let mut off = table as u32;
        for e in &self.entries {
            out.extend_from_slice(&off.to_le_bytes());
            out.extend_from_slice(&(e.len() as u32).to_le_bytes());
            off += e.len() as u32;
        }
        for e in &self.entries { out.extend_from_slice(e); }
        out
    }
}
```
